La idea: una web que se pasa como un folioscopio

Web de Stand By Me · 22 nov 2026

De dónde sale todo: la portada de la web contada como un librito de hojas dibujadas, que avanza con el scroll.

El punto de partida

La web tiene que hablar a propietarios de edificios y servir para enseñarla a inversores. No es para huéspedes ni para reservar. Su objetivo es reputación.

La idea

Un niño juega con algo que rueda. Poco a poco eso que rueda gana estructura y acaba siendo un hotel, y después muchos. Contado como un folioscopio: una hoja dibujada tras otra, pasadas a mano. En la web, el dedo es el scroll.

Cómo se reparte

  • Portada: el folioscopio Así nace un hotel, con el titular y el botón de contacto.
  • Qué hacemos: los oficios del niño como secciones.
  • Más abajo: el folioscopio Así crece el grupo, que desemboca en la cartera.
  • Los activos, cada uno como una ficha breve.

De dónde tomar ejemplo

De las webs de fondos de inversión para la estructura, con cartera a la vista y cifras de grupo. No para el tono, que es frío.
